Codex Cartographer

Interactive atlas of how a codebase works

Upload code, a research paper, or both. Code opens a line-by-line atlas; a paper-only upload opens a readable paper session.

Start mapping

Provide at least one of: a project zip, a single source file, or a PDF paper. All three fields are optional individually.

Try the live demo

Working — this can take up to a minute for larger projects…

Languages: Python, JS/TS, C/C++, MATLAB/Octave, Java, Go, Rust, R, Julia, and more.

  • code only → atlas
  • paper only → paper session
  • both → atlas + paper

Limits on this public demo: zip ≤ 25 MB, single file ≤ 5 MB, paper ≤ 20 MB.
